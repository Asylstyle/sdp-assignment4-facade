# Report worksheet

For an exercise based on this reference, write an explanation of the chosen problem,
a UML diagram matching any modifications, five annotated clean-code excerpts,
actual verification evidence, a conclusion with limitations, and the repository URL.

The complete reference report is [REPORT.md](REPORT.md). The implementation's class and
sequence diagrams are [UML.md](UML.md) and [SEQUENCES.md](SEQUENCES.md).
This worksheet is an optional teaching aid, not an unfinished project requirement.
